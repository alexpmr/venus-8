O GitHub pode exigir login para baixar artefatos de Actions. A [página Releases](https://github.com/alexpmr/venus-8/releases) terá downloads diretos depois da publicação de uma Release validada.

## Projeto

Sintetizador virtual analógico para Windows 10/11, com interface vintage, teclado virtual, MIDI USB e evolução planejada para efeitos, bancos de timbres, touch e VST3.
